## 1. Which pretreatment to do before doing dot ?

Before using the dot product instead of cosine similarity, you need to normalize the vectors. Normalization ensures that each vector has a unit length, which makes the dot product equivalent to the cosine similarity. This is important because the dot product of two vectors can be influenced by their magnitudes, whereas cosine similarity is a measure of the angle between the vectors, independent of their magnitudes.

## 2. What “argpartition” stand for ?
argpartition is a function in NumPy that returns the indices that would partition an array. It is similar to argsort, but it is more efficient when you only need the indices of the top n elements rather than the entire sorted array.
For example, np.argpartition(scores, -n)[-n:] will return the indices of the n highest scores in the array scores. This is more efficient than sorting the entire array if you only need the top n elements.
