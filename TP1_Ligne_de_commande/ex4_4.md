## Exercice 3 : bigram
### Unigrams (n=1)
```
tr -s '[:space:]' '\n' < RADIOS.txt | sort | uniq -c | sort -nr > unigrams.hist
```

### Bigrams (n=2)
```
tr -s '[:space:]' '\n' < RADIOS.txt | paste -d ' ' - - | sort | uniq -c | sort -nr > bigrams.hist
```

### Trigrams (n=3)
```
tr -s '[:space:]' '\n' < RADIOS.txt | paste -d ' ' - - - | sort | uniq -c | sort -nr > trigrams.hist
```

### Fourgrams (n=4)
```
tr -s '[:space:]' '\n' < RADIOS.txt | paste -d ' ' - - - - | sort | uniq -c | sort -nr > fourgrams.hist
```
### Q1: How many times does the 2-gram "it is" appear in this text?
```
grep -w "it is" bigrams.hist
```

### Q2: How many separate 3-grams are found in this text?
```
wc -l < trigrams.hist
```

### Q3: What is the most common 4-gram?
```
head -n 1 fourgrams.hist
```
